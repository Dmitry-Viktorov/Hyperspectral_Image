# Техническое задание: Обработка гиперспектрального изображения

## 1. Цель
Создать прототип обработки гиперспектрального куба из NetCDF-файла, сохранить данные в TIFF и проанализировать метаданные, в том числе сравнить их с метаданными файл-паспорта `.rsp`.

## 2. Исходные данные
- Файл: `AV320241005t175313_005_L1B_RDN_f6524bfe_RDN.nc`
- Группа данных: `radiance`
- Ожидаемый формат: гиперспектральный куб `radiance[b, y, x]` и вектор длин волн `wavelength`

> Примечание: пример в задании использовал файл `AV320231006t190153_018_L1B_RDN_cbeae6f8_RDN.nc`, но в репозитории доступен `AV320241005t175313_005_L1B_RDN_f6524bfe_RDN.nc`.

## 3. Задачи

1. Загрузка и визуализация данных
   - Открыть NetCDF-файл с помощью `xarray.open_dataset(..., group='radiance')`
   - Построить изображение одного спектрального слоя: `ds_cube['radiance'][50, :, :]`
   - Построить спектр для одной точки: `plt.plot(ds_cube.wavelength, ds_cube['radiance'][:, 100, 200])`

2. Экспорт в TIFF
   - Перезаписать данные гиперспектрального куба в многополосный TIFF через GDAL
   - Сохранить количество каналов, соответствующих длинам волн
   - Убедиться, что сохраняется тип данных и, при наличии, геопривязка

3. Анализ метаданных
   - Извлечь и задокументировать метаданные NetCDF-файла:
     - глобальные атрибуты
     - атрибуты переменных `radiance`, `wavelength` и других
     - координатную информацию и геопривязку
   - Извлечь метаданные TIFF-файла после записи
   - Сравнить найденные метаданные с метаданными из файл-паспорта `.rsp`
   - Определить пересечения по тегам, единицам измерения, описаниям каналов и другим значимым полям

## 4. Требования к реализации

- Язык: Python
- Библиотеки:
  - `xarray`
  - `matplotlib`
  - `osgeo.gdal` / `GDAL`
  - `numpy`
- Код должен содержать:
  - загрузку файла
  - визуализацию слоя и спектра
  - экспорт TIFF
  - вывод/сохранение списка метаданных

## 5. Ожидаемые результаты

- Рабочий Python-скрипт или Jupyter Notebook
- TIFF-файл с многополосным кубом
- Список найденных метаданных
- Анализ пересечений с метаданными `.rsp`
- Краткий отчет и выводы
